Logic Explanation

The Dungeon Loot Splitter is an event-driven JavaScript program that manages loot items, calculates total value, applies tax, and splits rewards among party members.

When loot is added, the addLoot() function takes the input values, validates them, assigns a random rarity, and stores the item in an array. The display is then updated using renderLoot().

The renderLoot() function loops through the array to display all loot items and calculate the total value. It then applies guild tax using guildTax() and displays the final total after tax.

The removeLoot() function deletes a loot item by name using findIndex() and splice(), then updates the display.

The splitLoot function calculates the taxed total and divides it by the party size to determine each member's share.

Overall, the program uses arrays, functions, loops, conditionals, and DOM manipulation to create an interactive loot system.
